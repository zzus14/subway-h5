# 长春地铁出行 H5

面向手机浏览器的长春地铁出行查询应用，支持线网浏览、站点查询与换乘路径规划。
**纯前端实现**（Vue 3 + Vite 5 + Vant 4），无后端、无数据库，线路与站点数据随代码打包。

线网规模：**8 条线路、148 座车站、26 个换乘站**。

## 功能

- **地铁图** —— 线网示意图，支持缩放、拖动、点击站点查看详情
- **站点查询** —— 按站名检索，查看途经线路、出入口与首末班
- **线路详情** —— 浏览单条线路的全部站点
- **路径规划** —— 输出推荐 / 少换乘 / 少步行三类方案
- **方案详情** —— 分段乘车指引，含耗时、换乘次数、步行距离

## 运行

需要 **Node.js 18 或更高版本**（[下载](https://nodejs.org/zh-cn/download)）。
仓库不含 `node_modules`，首次运行需联网安装依赖。

```bash
npm install     # 安装依赖
npm run dev     # 启动开发服务器 → http://localhost:5173
npm run build   # 打包生产版本到 dist/
```

## 目录结构

```
src/
├── views/        8 个页面
├── components/   线网示意图、站点选择器
├── data/         线路与站点数据（stations.json / lines.json）
├── utils/        路径规划算法
├── services/     数据访问层
└── router/       路由表
```

## 路径规划算法

三种方案对应三种边权：
**推荐**按总耗时最短；**少换乘**按 `60 × 换乘次数 + 耗时` 排序；**少步行**按 `4 × 步行距离 + 耗时` 排序。

计时口径：行车 2.5 分钟/站，换乘 4 分钟/次；站内换乘步行 180 米，东大桥出站换乘 420 米。
